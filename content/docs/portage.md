# Porter un jeu existant

Un jeu dont le code source existe (C, Pascal, BASIC, assembleur, JavaScript…) se traduit en PHP dans la
structure de JumPHP : ses écrans deviennent des scènes, ses objets des entités, sa boucle principale est celle
du moteur. [Moktar](/moktar) (le port d'OpenTitus) et [Sapiens](/sapiens) ont été faits ainsi.

- Choisissez le type **Portage d'un jeu existant** à la création, et dites dans la description où est le code
  d'origine : votre Claude s'en servira.
- Gardez les règles, les niveaux et les sensations d'origine ; créditez les auteurs et respectez la licence.
- Les données du jeu d'origine qui ne sont pas libres ne vont pas dans le dépôt public : déposez-les dans les
  **fichiers privés** du projet (Studio → le projet). Le jeu les charge comme ses propres fichiers.
